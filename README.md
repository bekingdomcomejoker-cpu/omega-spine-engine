## Usage

### Basic Example

```python
from omega_spine_engine import OmegaSpineEngine, SpineState
import time

# Initialize engine
engine = OmegaSpineEngine()

# Create initial state
state = SpineState(
    meaning=0.5,
    awareness=1.0,
    love=0.9,
    truth=0.8,
    complexity=0.1,
    timestamp=time.time()
)

# Step the engine
state = engine.step(state, input_signal=0.5)

# Get state as dictionary
state_dict = engine.get_state_dict(state)
print(state_dict)
```

### Simulation

```python
# Simulate multiple steps
input_signals = [0.1, 0.5, 2.0, 5.0, 0.1]  # Various stressors
states = engine.simulate(state, input_signals, steps=100)

# Check engine status
status = engine.get_status()
print(f"Collapse events: {status['collapse_events']}")
print(f"Kingdom power activations: {status['kingdom_power_activations']}")
```
